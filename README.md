# DGN Studio Nesting — kurulum dosyaları

Lazer kesim için DXF yerleştirme (nesting) programının Windows kurulum dosyaları.

En son sürüm: **[Releases](https://github.com/Zamparra76/Nesting/releases/latest)** → `DGN_Studio_Nesting_vX.Y_kurulum.exe`.
Kurulu program yeni sürümü kendisi bulur ve "Güncelle" diye sorar.

> Windows ilk kurulumda "bilgisayarınızı korudu" uyarısı gösterebilir: **Ek bilgi → Yine de çalıştır**.
